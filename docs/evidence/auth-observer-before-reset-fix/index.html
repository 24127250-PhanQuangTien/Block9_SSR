Block8 — server/DB/browser thật trong schema test

Không có cookie/password/OTP/token/đáp án CAPTCHA trong báo cáo. Bảng Network/Cookies/DB là dữ liệu quan sát đã che, không giả làm ảnh DevTools. Không phải dữ liệu nhà hàng production.

  1. mandatory secrets and cookie production policy · UI · Network/Cookies/DB
  2. all unauthenticated CRUD GET/POST/override requests redirect 303 before writes · UI · Network/Cookies/DB
  3. CSRF and Origin reject public auth submissions · UI · Network/Cookies/DB
  4. register CAPTCHA missing/wrong/expired/reused/other-session/other-purpose is one-use and creates no account or mail · UI · Network/Cookies/DB
  5. register normalization, role whitelist, Argon2id and pending password preservation · UI · Network/Cookies/DB
  6. pending cannot login, OTP activation is atomic and does not auto-login · UI · Network/Cookies/DB
  7. resent OTP rejects old code and accepts new code through HTTP · UI · Network/Cookies/DB
  8. OTP resend cooldown, replacement, expiry, attempts and lock persist · UI · Network/Cookies/DB
  9. login generic errors, server CAPTCHA threshold, persistent 10-failure lock and cookie rotation · UI · Network/Cookies/DB
  10. DB session survives real server restart; logout and stale store writes cannot revive sid · UI · Network/Cookies/DB
  11. idle, absolute expiry and inactive users are rejected server-side · UI · Network/Cookies/DB
  12. forgot generic response, canonical reset origin, single token and read-only GET reset · UI · Network/Cookies/DB
  13. reset is atomic, invalidates all sessions, cannot authenticate as token or activate pending · UI · Network/Cookies/DB
  14. IP budgets are enforced independently of account and cookie · UI · Network/Cookies/DB
  15. authenticated CRUD all three entities, CSRF, override, validation and pagination · UI · Network/Cookies/DB
  16. CAPTCHA consumes valid challenges even for omitted, array or oversized answers · UI · Network/Cookies/DB
  17. resend hides pending cooldown when generic quotas and account counters diverge · UI · Network/Cookies/DB
  18. correct CAPTCHA and password cannot bypass a lock persisted through restart · UI · Network/Cookies/DB
  19. reset token is rejected as password, activation OTP and signed session · UI · Network/Cookies/DB
  20. forgot paired timing observations keep identical public status and content · UI · Network/Cookies/DB
